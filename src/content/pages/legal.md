本站主要面向中华人民共和国境内访客提供内容，无意主动向欧盟成员国、英国、美国加利福尼亚州居民提供服务，并未针对上述地区制定专项合规方案。如果您在上述地区访问，请留意：本站的各项数据处理活动依照中华人民共和国法律执行，不会遵循地区性隐私法案的相关义务；您继续访问本站，即表示您同意此安排。如您认为当地法律赋予您额外权利，请通过邮箱联系我们。

### 一、信息收集说明

普通访客仅浏览网页时，我们不会主动收集、存储可识别您个人身份的信息。

当您通过 Giscus 评论组件发表评论时，需要使用 GitHub 账号授权登录。您的 GitHub 用户名、头像以及您发布的评论内容，将会公开存储于本仓库的 GitHub Discussions 中，其他访客可以看到该评论信息。您有权联系我们以对您的评论查阅、复制、更正、删除等操作。我们不会获取或保存您的 GitHub 账号密码。

如果您订阅了本仓库的 GitHub Issue，GitHub 将依据您账号绑定的电子邮箱，自动向您推送该 Issue 的后续更新邮件；邮件订阅管理、退订操作均由 GitHub 平台控制，本站无法读取您的邮箱，也无权取消您的订阅。

嵌入的 Giscus 组件作为第三方站点，可在您的设备保存本地站点数据，相关存储行为由 Giscus.app 负责。

本站使用两套独立的匿名流量统计工具：Umami‑Cloud 以及 Cloudflare Web Analytics。两项服务目标为匿名统计，不会保存访客原始 IP；仅收集汇总后的匿名访问数据，例如浏览量、设备类型、浏览器型号、大致访问地区，无法定位到具体个人。统计过程中可能会在浏览器本地生成少量站点存储数据。

### 二、第三方服务商

本站运行依赖以下第三方服务商，服务商有可能处理访客相关数据：

1. **GitHub（源码存储）与 Giscus**
本站源代码存放于 GitHub，网页托管、CDN 加速、安全防护均由 Cloudflare Pages 提供；评论功能由 Giscus 提供，评论数据保存在 GitHub Discussions。评论登录采用 GitHub OAuth 授权，话题邮件推送服务由 GitHub 提供。GitHub 公司总部位于美国加利福尼亚州，可能处理您的相关数据。

详情请查阅 GitHub 隐私政策：[https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

2. **Cloudflare（托管、CDN、安全防护与匿名流量分析）**

本站使用 Cloudflare 提供网页托管、反向代理、内容加速、人机防护以及匿名网页流量统计服务。在中转流量过程中，Cloudflare 出于安全以及数据分析目的可能处理您的 IP 地址。Cloudflare 总部位于美国加利福尼亚州。

Cloudflare 隐私政策：[https://www.cloudflare.com/privacypolicy/](https://www.cloudflare.com/privacypolicy/)

3. **Umami‑Cloud（匿名访问统计）**

本站借助 Umami‑Cloud 采集匿名网站使用数据，该服务目标为匿名统计，不记录原始访客 IP。

Umami‑Cloud 隐私政策：[https://umami.is/privacy](https://umami.is/privacy)

### 三、Cookie 与本地存储说明

部分由本站域名下发的 Cookie、本地站点存储，来源于本站接入的第三方服务，包括但不限于 Cloudflare、Umami‑Cloud、Giscus。

该类数据由对应的第三方组件生成与控制，本站无法完全预知、管控其全部行为。您可以查阅对应第三方服务商的隐私声明获取详情。

### 四、儿童隐私
